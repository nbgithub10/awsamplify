# HSC Engineering Studies Quiz

Interactive quiz application for HSC Engineering Studies practice and revision.

## Description

A web-based quiz application designed to help students prepare for the HSC Engineering Studies exam. Practice with multiple choice and short answer questions across different syllabus sections.

## Features

- **Section Selection**: Choose from different Engineering Studies syllabus sections
- **30 Multiple Choice Questions**: Practice with varied MC questions
- **20 Short Answer Questions**: Develop written response skills
- **Instant Feedback**: Get immediate feedback on your answers
- **Progress Tracking**: Monitor your progress throughout the quiz
- **Results Summary**: View detailed results and performance analytics

## How to Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:5173`

## Technology Stack

- **React**: UI framework
- **Vite**: Build tool and development server
- **JavaScript/JSX**: Core programming language
